「ミニかわロボ」は[かわロボ](https://kawasaki-sanshinkaikan.jp/robo/)を参考に「どこでも気軽にできる手のひらサイズの小型対戦ロボット競技」をコンセプトに考案した規格です。

3Dプリンタと少しの電子工作知識があれば誰でも安価に製作でき、ちらかった机の上でも外出先でもどこでも熱いバトルが楽しめるのが特徴です。

# 基本ルール抜粋
+ サイズ：100mm × 150mm以内（スタート時）
+ 重量：150g以下
+ 動力：マイクロサーボ（幅12mm）
+ 勝敗：相手をひっくり返して5カウントか、場外に押し出せば勝利。
詳細は[ルール](docs/rule.md)をご覧下さい。
